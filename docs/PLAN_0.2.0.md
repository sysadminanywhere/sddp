# SDDP 0.2.0 — пилот REST-интеграции

Цель версии — пройти от импорта OpenAPI до реальных запросов из сгенерированного Java-клиента. Пилот моделирует API заказов и проверяется локально без доступа к внешнему сервису.

- [x] Сохранить пилотный контракт с `GET /orders/{id}` и `POST /orders`. Проверить параметр пути, параметр запроса, JSON-тело и схему ответа.
- [x] Добавить предварительный просмотр OpenAPI, выбор операций и импорт в существующий сервис. Повторный импорт той же версии сохраняет API, их идентификаторы и существующие связи.
- [x] Передавать HTTP-метод, путь и параметры в IR и Java-генератор. Сохранить поведение существующих REST-связей и snapshot v1. Для связи без HTTP-метаданных использовать POST.
- [x] Проверить импорт, маппинг и перенос в защищённое окружение. Скомпилировать результат и выполнить оба запроса к тестовому HTTP-сервису. Включить сценарий в CI.

Критерий готовности — сценарий выполняется без ручной правки схем и сгенерированного Java-кода.

## Проверка

- Пилотный контракт хранится в [orders.openapi.json](examples/orders.openapi.json).
- Браузерный сценарий проверяет выбор операций, импорт, маппинг, перенос в PROD и генерацию клиента.
- PostgreSQL-тест компилирует сгенерированный Java-код, проверяет реальные GET и POST и восстанавливает метаданные из snapshot v1.
- Пройдены 68 тестов Maven, сценарий восстановления базы в Docker Compose и откат до `v0.1.0`. Проверки пилота включены в CI.
